Method and exclusions

Latest Q3 filing per client and registrant (amendments dropped). The filter t.filing_uuid IS NOT NULL excluded 20,897 filings in 2024 and 23,062 in 2026 whose activity text never says tariff, to isolate tariff-mentioning filings; the excluded filings total $1,161M and $1,328M, so with them included all-filing spending rose only 30%, against +197% without them. Any mention of tariff includes multi-issue filings, which inflates dollars relative to a tariff-only measure.

Misleading context

  • The headline frames the surge as driven by Trump; filings show more tariff mentions, not why.
  • Source is a Pence-founded group opposed to tariffs; the piece omits that AAF's Q1 (+655%) and Q2 (+690%) readings were higher, and that 2024 is a pre-tariff base.
  • Counts (14 vs 2, 105 vs 26) depend on an undisclosed definition; a broad one gives 73 vs 21 and 436 vs 130.
  • Canada trade drop ($50B, 6.5%) unverified.

WITH f AS (
 SELECT filing_uuid, filing_year, client_id, registrant_id, COALESCE(income,0) inc, COALESCE(expenses,0) exp,
  ROW_NUMBER() OVER (PARTITION BY filing_year, client_id, registrant_id ORDER BY dt_posted DESC) rn
 FROM law.lobbying_filings
 WHERE filing_period='third_quarter' AND filing_year IN (2024,2026) AND filing_type LIKE 'Q3%'),
l AS (SELECT * FROM f WHERE rn=1),
t AS (SELECT DISTINCT filing_uuid FROM law.lobbying_activities WHERE lower(description) LIKE '%tariff%'),
c AS (SELECT l.filing_year, l.client_id, SUM(inc+exp) tot, MAX(CASE WHEN t.filing_uuid IS NOT NULL THEN 1 ELSE 0 END) tf, SUM(CASE WHEN t.filing_uuid IS NOT NULL THEN inc+exp ELSE 0 END) ttot FROM l LEFT JOIN t ON t.filing_uuid=l.filing_uuid GROUP BY l.filing_year, l.client_id)
SELECT filing_year, SUM(ttot) tariff_income_total, SUM(CASE WHEN tot>1000000 THEN 1 ELSE 0 END) n_over_1m_all, SUM(CASE WHEN tot>100000 THEN 1 ELSE 0 END) n_over_100k_all, SUM(CASE WHEN tf=1 AND tot>1000000 THEN 1 ELSE 0 END) n_over_1m_tariffclients, SUM(CASE WHEN tf=1 AND tot>100000 THEN 1 ELSE 0 END) n_over_100k_tariffclients, SUM(CASE WHEN ttot>1000000 THEN 1 ELSE 0 END) n_tariff_filings_over1m, SUM(CASE WHEN ttot>100000 THEN 1 ELSE 0 END) n100
