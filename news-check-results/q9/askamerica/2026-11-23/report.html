Warehouse check and exclusions

transport.fatal_crashes (FARS 2024). I approximated local sunset (solar formula, longitude-based time zones, DST) and counted crashes within two hours either side. Window crashes: autumn 2,290; spring 2,024; summer 2,060; winter 1,789. Daily average autumn 25.2 vs winter 19.7, +28%. Deaths autumn 2,443, winter 1,940 (article 2,497 and 1,979). Total 8,163 vs 8,334 claimed. My pre/post split (+46%) does not reproduce 57.8% because I use whole crash hours.

Exclusions: the query dropped crashes with missing hour, latitude or longitude (FARS unknown sentinels) and Arizona and Hawaii were treated as not observing DST. I did not run it without the exclusions, so the 8,163 vs 8,334 gap is partly this and partly the approximation.

Source arithmetic: 5,101/3,233 = +57.8%; 543/276 = +96.7%; seasonal deaths sum to 8,921; 27.3/19.0 = +43.7% (source says 43.4%, unrounded inputs).

The 13 article-linked share URLs were fetched; they are social share buttons carrying only the headline.

Misleading framing

Headline says crashes 'rise' in autumn, but it is a one-year cross-season comparison; the source itself says one year cannot establish a recurring pattern and the article omits that. The source is a law firm marketing piece, not disclosed. Counts are not risk (no exposure; autumn sunsets coincide with the evening commute).

What This Report Does Not Answer

  • Exact reproduction of sunset-window counts: Warehouse has no sunset times; approximated with a solar formula, so only the seasonal gap was reproduced approximately.

Every query behind this report

1 warehouse call ran in this session, in order. Each is reproducible against the same snapshot.

query — 4 rows — 871 ms
WITH b AS (
SELECT st_case, crash_date, hour, latitude, longitude, fatalities, state_name,
 CAST(EXTRACT(doy FROM crash_date) AS DOUBLE) n,
 CASE WHEN longitude > -82.5 THEN -5 WHEN longitude > -97.5 THEN -6 WHEN longitude > -112.5 THEN -7 WHEN longitude > -127 THEN -8 WHEN longitude > -141 THEN -9 ELSE -10 END AS std_off
FROM transport.fatal_crashes WHERE year=2024 AND hour IS NOT NULL AND latitude IS NOT NULL AND longitude IS NOT NULL AND latitude BETWEEN 18 AND 72 AND longitude BETWEEN -170 AND -65),
c AS (
SELECT *, 23.44*sin(radians(360.0/365*(n-81))) AS dec_deg,
 9.87*sin(radians(2*360.0/364*(n-81))) - 7.53*cos(radians(360.0/364*(n-81))) - 1.5*sin(radians(360.0/364*(n-81))) AS eot_min,
 CASE WHEN crash_date >= DATE '2024-03-10' AND crash_date < DATE '2024-11-03' AND state_name NOT IN ('Arizona','Hawaii') THEN 1 ELSE 0 END dst
FROM b),
d AS (
SELECT *, acos(GREATEST(-1.0,LEAST(1.0,(sin(radians(-0.833)) - sin(radians(latitude))*sin(radians(dec_deg)))/(cos(radians(latitude))*cos(radians(dec_deg)))))) h_rad FROM c),
e AS (
SELECT *, 12 - longitude/15.0 - eot_min/60.0 + degrees(h_rad)/15.0 + std_off + dst AS sunset_local FROM d),
f AS (SELECT *, CASE WHEN month(crash_date) IN (9,10,11) THEN 'autumn' WHEN month(crash_date) IN (12,1,2) THEN 'winter' WHEN month(crash_date) IN (3,4,5) THEN 'spring' ELSE 'summer' END season,
 month(crash_date) mo FROM e WHERE hour+0.5 BETWEEN sunset_local-2 AND sunset_local+2)
SELECT season, COUNT(*) win_crashes, SUM(fatalities) win_deaths,
 SUM(CASE WHEN hour+0.5 < sunset_local THEN 0 ELSE 1 END) post, SUM(CASE WHEN hour+0.5 < sunset_local THEN 1 ELSE 0 END) pre
FROM f GROUP BY season
