# Fact-check: Daily Caller, "America's housing market takes another hit..." (Oct 20, 2026, Jack McGeever)

Fetch succeeded. Grade: **1 Pinocchio (mostly accurate)**. The headline numbers match primary sources; a few claims are unverified and one framing is incomplete.

| Claim | Verdict | Evidence |
|---|---|---|
| Single-family starts -4.6% to 859k (Aug revised 900k) | True | Census new residential construction, Sept 2026 (released Oct 20) |
| Single-family permits -4.0% to 845k | True | Census |
| Total starts -5.2% to 1.221M, -7.4% y/y | True | Census |
| Total permits -0.2% to 1.400M | True | Census (permits were also 3.0% below Sept 2025, which the piece omits) |
| Completions -14% y/y | Not checked here | Could not reach the table |
| 30-yr rate 7.40% vs 6.27% a year ago | True, dated | Freddie Mac reported 7.40% the week before the piece. It fell to 7.32% on Oct 22, two days after publication |
| "Near highest in three years" | Not verified | |
| Payment about $2,313 vs $2,061 (+$252) | True | I recomputed: $334,000 loan at 7.40% = $2,313; at 6.27% = $2,061 |
| Median existing-home price $417,500 | True | NAR. Up 1.3% y/y, which the piece does not mention |
| Existing-home sales +1.5% to 3.99M, below year-ago | True | NAR. Sales were -2.2% y/y |
| NAHB index 29 (from 32), lowest since June 2012 | True | NAHB/Wells Fargo, released Oct 19 |
| 43% of builders cut prices, highest since 2020; average cut 6% | True | NAHB. Some outlets say "record", which overstates it. This piece says "since 2020", which is accurate |
| 65% used incentives | True | NAHB |
| Prospective buyer traffic 18 | Not verified | |
| Dietz quote on supply-side and affordability pressures | Plausible | Dietz did comment on buyer traffic, but I did not find the exact wording |
| Builders cite materials, diesel and labor costs | Consistent | NAHB cites rates, energy and materials costs |
| Record first-time buyer age of 40 | Plausible | Based on prior NAR profile data; not rechecked |
| 483,000 new homes for sale in August, 8.5 months' supply | Not checked here | |

## Misleading or missing context
- The 7.40% rate was the latest reading when published, but it was already a peak. The next week's figure was 7.32%.
- The piece is all bad news. It omits that existing-home sales rose month over month, that the median price is still rising and that inventory is at 4.8 months.
- Total permits being nearly flat is minor next to the single-family drop.
