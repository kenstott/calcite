# Fact-check: CNBC, "Homebuilder sentiment plunges to 14-year low, leading more builders to drop prices" (2026-11-17)

Method: WebFetch of the CNBC piece (summarized, not verbatim), NAHB press release, and web searches. Not exhaustive; regional point changes and the year-ago rate could not be confirmed.

## Claims
| Claim | Verdict | Source |
|---|---|---|
| HMI fell 4 pts to 25 in November, lowest since April 2012 | True | NAHB press release (nahb.org, 2026/11); Inman, TheStreet, RISMedia |
| Index was 38 a year earlier | True (Nov 2025 = 38) | NAHB Nov 2025 release |
| 46% of builders cut prices, highest post-Covid share | True | NAHB release |
| 68% used incentives, post-Covid high | True | NAHB release |
| Current sales 28 (down 6), future sales 30 (down 2) | Levels true (28, 30); point changes not independently confirmed | NAHB release |
| Buyer traffic 16, down 2, lowest in 15 years excluding pandemic start | True | NAHB release |
| 30-yr fixed 7.51% on Monday | Plausible/true on Mortgage News Daily basis (7.48% on Nov 17, down 0.03 from prior day, implying 7.51% Nov 16). Not Freddie Mac, whose weekly figure was 7.11% (Nov 12) | mortgagenewsdaily.com |
| 6.38% a year earlier | Not checkable here (no MND Nov 2025 figure retrieved) | n/a |
| Regional 3-month averages: NE 34, MW 35, S 27, W 23 | Levels true; stated changes (-4, -5, -3, -3) not confirmed | NAHB release |
| Owens: immigration enforcement keeping workers off job sites | True (attributed paraphrase) | NAHB release |
| Dietz: tariffs raise material costs; labor shortage | True | NAHB release |
| Dietz quote: "Mortgage rates above 7%, softer consumer confidence and an uncertain economic outlook are holding buyers back." | True, verbatim | NAHB/secondary coverage |

## Rating: 1 Pinocchio (essentially accurate; 0 would be fully clean)
Reasons: all checkable headline facts match NAHB. Minor issue only: the 7.51% rate is a daily lender-index figure (Mortgage News Daily) that runs about 40 bp above Freddie Mac's widely cited weekly average (7.11%); the article does not make the distinction clear in the summary available to me.

## Potentially misleading context
- "Plunges" is fair for a 4-point drop but the index is a diffusion index; 25 means most builders rate conditions poor, not that 25% of anything occurred.
- Average price cut held at 6% for eighth straight month (NAHB), so the share cutting rose while depth did not; the headline "drop prices" does not convey this.
- Rate comparisons across sources are not like-for-like.
