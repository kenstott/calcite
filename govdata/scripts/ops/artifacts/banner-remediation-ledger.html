This ledger is an archive — tracking moved to GitHub issues

Every unit on this page was migrated to kenstott/govdata-ops on 10 September 2026, and that private repo is the store of record from now on. Remediation units became type:remediation issues, each filed as a sub-issue of the defect it serves; the infrastructure table below became type:infra issues. Nothing writes to this page any more. It is kept because the evidence in it — the row counts, snapshot timestamps and commit hashes behind each verdict — is the record of how each unit was actually verified.

The ledger-runner's queue is now a query rather than this table: gh issue list -R kenstott/govdata-ops --label type:remediation --label status:ready-to-run. The prerequisite that used to live in an evidence paragraph — “do not run this against production yet” — is now the status:needs-dq label, which that query excludes, so an unvalidated job cannot be picked up by accident. Label vocabulary and the issue shapes are in docs/ops/defect-tracking.md.
