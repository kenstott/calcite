This register is an archive — tracking moved to GitHub issues

Every entry on this page was migrated to kenstott/govdata-ops on 10 September 2026, and that private repo is the store of record from now on. Defects became type:defect issues keeping their D-NNN id in the title, so an older reference still resolves by search; the Dataset Availability Research table became type:sourcing issues. Nothing writes to this page any more. It is kept because the root-cause analysis and live evidence in each entry is the record of how the defect was actually traced.

The dispositions below are now labels: status:* while open, resolution:* at close. The one that used to live only in prose — a fix committed but not yet DQ-validated — is status:needs-dq, which the ledger-runner's queue excludes, so an unvalidated job cannot be picked up by accident. Whether a defect has a production job filed is now a query against its sub-issues rather than a name match across two documents. Label vocabulary and issue shapes are in docs/ops/defect-tracking.md.
