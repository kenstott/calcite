Setup is running now

The AskAmerica MCP setup window should have opened behind this installer. It downloads the query engine (about 450 MB) to ~/.askamerica/engine and shows a progress bar while it does. Let it finish before continuing — it runs once, and the pip package shares the same copy.

  1. In the setup window, paste your API key (free key at askamerica.ai) and click Configure Claude Desktop.
  2. Quit and reopen Claude Desktop. AskAmerica then shows up as a connected tool, with list_schemas, list_tables, describe_table, and query.

No setup window? Open AskAmerica MCP from your Applications folder — it picks up exactly where the installer left off. What happened is recorded in ~/.askamerica/last-install.txt.

If you skip setup entirely, Claude Desktop downloads the engine the first time it starts the server, which can take a few minutes. A progress window appears for that too, so it is never a silent wait.
