Two steps left

  1. Open AskAmerica MCP from your Applications folder, paste your API key (free key at askamerica.ai), and click Configure Claude Desktop. The setup window may have opened already — if so, just use it.
  2. Quit and reopen Claude Desktop. AskAmerica then shows up as a connected tool, with list_schemas, list_tables, describe_table, and query.

The first launch downloads the query engine (about 450 MB) to ~/.askamerica/engine and shows a progress window. This happens once; the pip package shares the same copy.
